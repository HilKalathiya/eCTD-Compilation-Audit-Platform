git = a tool that saves numbered snapshots of a folder
commit = one saved snapshot of the folder
baseline = the snapshot you compare future changes against
.gitignore = a list of files git must not save
temp repo = a short-lived scratch git folder deleted after the test
subprocess = running another program from inside Python
false alarm = a warning that fires when nothing is wrong
planted mistake = an error put in on purpose to check an alarm rings
co-author trailer = a Co-Authored-By line at the end of a commit message, makes GitHub list that person
force-push = overwrite the online history with your local one (needed after rewriting commits)
Docker = tool that runs programs in sealed boxes so they behave the same everywhere
container = one running sealed box made from an image
volume = disk space kept outside a container so data survives restarts
profile = a name in docker-compose.yml that lets you start only some containers
requirement = a promise the system must keep (ids UR-01...)
risk = something that could break a promise (ids RK-01...)
control = the thing that stops or catches a risk
GAMP 5 = pharma guide for proving software does what its written requirements say
context = what Claude holds in mind during one session
MCP server = a connection to an outside tool that adds tools to Claude
token = a small chunk of text, about 4 letters
/clear = wipes the chat so Messages cost drops to zero
dataclass = a short way to define a record with named fields
frozen = cannot be changed after it is created
round trip = save to text and load back; the result must be identical
regex = a pattern that text must match exactly
whitelist = only the listed things are allowed, everything else is refused
status line = the bar at the bottom of Claude Code, fed by a script
stdin = text sent into a program from outside
JSON = text format of labelled values, like {"a": 1}
role = a database login with its own list of allowed actions
permission = one allowed action (read, insert...) granted to a role
SECURITY DEFINER = a database function that runs with its owner's rights, not the caller's
append-only = new rows can be added but never changed or removed
CHECK constraint = a rule stored in the table itself; every row must pass it
defence in depth = several independent checks, so one failing does not let bad data in
quarantine = a shelf where rejected rows are kept with the reason, never deleted
false alarm = a good row the gate wrongly rejected
rule table = a plain file listing allowed units and believable ranges
hook = a script Claude Code runs automatically at set moments
exit code 2 = a hook's way of saying "block this action"
PreToolUse = the hook moment just before a tool runs
Decimal = exact base-10 number type, so 0.1 is exactly 0.1 (float is not)
lineage = whether a fact is an original, a copy, or unknown
route = one independent source document that gives a value
drift = a source changed after we stored its number
graph = data stored as dots (nodes) joined by lines (relationships)
Cypher = the query language of Neo4j
MERGE = Cypher command: create if missing, else reuse
cross-field check = a rule that compares two numbers from the same row
dry run = run the job and count results without storing anything
word box = the rectangle (x0,y0,x1,y1) around one word on a PDF page
text layer = real text inside a PDF (not a picture of text)
locator = the address of a fact's source, e.g. page=3;box=317,204,329,218
blind entry = typing a value twice without seeing your first answer
refused = the check said no, so no fact is made
