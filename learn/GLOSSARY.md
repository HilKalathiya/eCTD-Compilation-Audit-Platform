git = a tool that saves numbered snapshots of a folder
commit = one saved snapshot of the folder
baseline = the snapshot you compare future changes against
.gitignore = a list of files git must not save
temp repo = a short-lived scratch git folder deleted after the test
subprocess = running another program from inside Python
false alarm = a warning that fires when nothing is wrong
planted mistake = an error put in on purpose to check an alarm rings
co-author trailer = a Co-Authored-By line at the end of a commit message, makes GitHub list that person
force-push = overwrite the online history with your local one (needed after rewriting commits)
Docker = tool that runs programs in sealed boxes so they behave the same everywhere
container = one running sealed box made from an image
volume = disk space kept outside a container so data survives restarts
profile = a name in docker-compose.yml that lets you start only some containers
requirement = a promise the system must keep (ids UR-01...)
risk = something that could break a promise (ids RK-01...)
control = the thing that stops or catches a risk
GAMP 5 = pharma guide for proving software does what its written requirements say
context = what Claude holds in mind during one session
MCP server = a connection to an outside tool that adds tools to Claude
token = a small chunk of text, about 4 letters
/clear = wipes the chat so Messages cost drops to zero
